# Apps

Small apps built with Claude.

## Orbit Explorer

A 3D solar system you can explore: planets and their moons, Earth's seasons, Moon phases, lunar eclipses, and the satellites and space junk circling Earth.

**Open it:** https://cflo88.github.io/apps/orbit-explorer/

Built with [three.js](https://threejs.org/). Planet maps by [Solar System Scope](https://www.solarsystemscope.com/textures/) (CC BY 4.0).
